5. PERSONA DEPENDENCY DIAGRAM — WHICH TEAM NEEDS WHICH PERSONAS

TEAM-TO-PERSONA DEPENDENCY MAP
-------------------------------

CAUSES PLATFORM (UX + Product)
    Needs: Prospect, Regular Supporter, HID, Clarity Seeker, Impact Believer
    Notes: Conversion + simplicity focus

N2N (Peer-to-Peer Fundraising)
    Needs: Influencer, College Mobilizer, Social Circle Fundraiser,
           Emotional-Authentic
    Notes: Shareability + urgency + storytelling

COMMUNITY APP (FCP Experience)
    Needs: FCP Director, Health Worker, Educator, Accountant, Pastor
    Notes: Task clarity + offline + low bandwidth

CX / GROWTH / MARKETING
    Needs: Prospect, Influencer, Emotional-Authentic, Supporting Church
    Notes: Messaging + acquisition strategy

ANALYTICS / BEHAVIORAL SCIENCE
    Needs: All Motivational Personas
    Notes: Experimentation + segmentation

LEADERSHIP / EXECUTIVES ([name omitted], [name omitted], etc.)
    Needs: High Impact Donor, Faith-Aligned Steward, FCP Pastor
    Notes: Stewardship + trust alignment

6. PERSONA SELECTION DECISION TREE

For PMs and Designers picking the right persona to design for.

PERSONA DECISION TREE
---------------------

START
 |
 |-- Is the user giving for the first time? --------- YES ---> A.1.1 Prospect + A.2.1 Clarity Seeker
 |                                                     NO
 |
 |-- Is the user giving again (not first time)? ---- YES ---> A.1.2 Regular Supporter + A.2.2 Impact Believer
 |                                                     NO
 |
 |-- Is the gift large or strategic? --------------- YES ---> A.1.3 HID + A.2.4 Faith-Aligned Steward
 |                                                     NO
 |
 |-- Is the user raising funds for others? --------- YES
 |         |
 |         |-- Do they mobilize an online audience? ----> A.1.4 Influencer / Advocate + A.2.3 Emotional-Authentic
 |         |
 |         |-- Are they a college team/group? ---------> A.1.5 College Mobilizer
 |         |
 |         |-- Are they raising from friends/family? --> A.1.7 Social Circle Fundraiser
 |
 |-- Is it a church or ministry team? -------------- YES ---> A.1.6 Supporting Church
 |
 |-- Is the user an FCP? --------------------------- YES
           |
           |-- Operational lead? -------------> A.3.1 FCP Director
           |-- Health-related tasks? ---------> A.3.2 Health Worker
           |-- Education tasks? --------------> A.3.3 Educator
           |-- Financial tasks? --------------> A.3.4 Accountant
           |-- Leadership / pastoral? --------> A.3.5 Pastor / Church Leader
