Research Proposal: Causes Usability Benchmark Re-Test

Prepared for: @AThompson8 , @SLamb2
Prepared by: Anil
Date: July, 21, 2025 - Aug 13, 2025

Overview

This proposal outlines the structure for a benchmark usability re-test of the Causes platform. The goal is to validate UX improvements, quantify user experience across core flows, and establish repeatable metrics using Lyssna. The tasks are derived from validated research themes and post-production strategy documents, with integration of Marginal Willingness to Pay (MWTP) insights and a catch trial to test platform resilience.

Objectives

  • Benchmark key user flows for donation discovery, trust, and checkout.
  • Capture repeatable quantitative metrics (SUS, CSAT, NPS, TLX).
  • Evaluate user comprehension of donation transparency and trust signals.
  • Measure behavioral intent via MWTP allocation tasks.
  • Test system resilience using a catch trial (controlled failure).

Test Platform: Lyssna

Tool: Lyssna for unmoderated usability testing)
Format: Unmoderated task-based test with follow-up survey
Target Users: New and returning donors, Next-Gen, Current-Gen, other demographic variables

Core Benchmark Tasks

Task 1: Discover and Select a Cause

  • Instruction: “Search for a cause that aligns with your values. Use filters or search if needed, and select one that feels meaningful to you.”
  • Metrics: Task Time, Task Success, Ease of Use (7-pt), Open-Ended Feedback

Task 2: Understand Cause Details & Allocation

  • Instruction: “Review the details of the cause you selected. Try to understand how donations will be used.”
  • Metrics: Time on Page, Trust Confidence (>=75%), SUPR-Q (Information Clarity), Open-Ended Feedback

Task 3: Simulated Donation + MWTP Prompt

  • Instruction: “Proceed to donate to this cause as if you were making a real donation. Select an amount and complete the donation process.”
  • MWTP Prompt: “Imagine you have $10 to donate across three causes. How would you split it between:
    • The cause you chose
    • A featured education cause
    • An urgent health cause
      Or select ‘I would not donate today.’”
  • Metrics: Task Time, Ease of Use, CSAT, Trust, Allocation Breakdown (MWTP), Open-Ended Feedback

Task 4: Navigate Using Filters (Wayfinding UX)

  • Instruction: “Use filters to find a cause related to ‘Education’ or ‘Emergency Relief.’”
  • Metrics: Task Time, Filter Use, Ease of Use, Open-Ended Feedback

Task 5: Evaluate Trust Indicators (Social Proof)

  • Instruction: “Before donating, check to see if you can find reviews, testimonials, or other signs that Compassion is a trustworthy organization.”
  • Metrics: Trust Score, Engagement Rate, NPS, Open-Ended Feedback

Task 6: Catch Trial – Search for a Non-Existent Cause

  • Instruction: “Search for a cause that supports clean water access in urban communities. Use filters and the search bar.” (Note: No such cause exists)
  • Metrics: Time on Task, Error Recovery, Frustration Indicators, CSAT, Exit Behavior

Optional Task 7: Post-Donation Feedback & Impact Tracking

  • Instruction: “Check for a confirmation or thank-you message. Look for ways to share your donation or receive updates about its impact.”
  • Metrics: Engagement Rate, CSAT, Open-Ended Feedback

Summative Metrics

  • System Usability Scale (SUS)
  • NASA-TLX (Workload Assessment)
  • Customer Satisfaction (CSAT)
  • Net Promoter Score (NPS)

Next Steps

  • Finalize test script and MWTP module integration
  • Review tasks with design and product
  • Deploy via Lyssna with 30-50 users
  • Create ScoreCard with CVG 4D
