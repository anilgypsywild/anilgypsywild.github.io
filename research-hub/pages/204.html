Research Portfolio Site

This folder contains a standalone static portfolio site built from the research documents already in this repository.

Files

  • index.html contains the page structure.
  • styles.css controls the visual design and responsive layout.
  • script.js stores the case-study content and filtering behavior.

Open locally

  1. Open index.html in a browser, or
  2. Run a simple local server from this folder if you want a cleaner preview.

Example:

cd research-portfolio
python3 -m http.server 4173

Then visit [reference omitted].

Deploy to GitHub Pages

This repo now includes a GitHub Actions workflow at .github/workflows/deploy-pages.yml.

To publish:

  1. Push this repo to GitHub.
  2. In GitHub, open Settings > Pages.
  3. Set Build and deployment to GitHub Actions.
  4. Push to the main branch.
  5. GitHub will publish the contents of research-portfolio/.

The live URL will usually look like:

https://<your-github-username>.github.io/<repo-name>/

Good next edits

  • Replace the placeholder name or add your preferred formatting.
  • Add contact details or a LinkedIn link before public publishing.
  • Swap or redact any internal language that should not appear externally.
  • Update the case-study copy in script.js if you want a more public-facing tone.
