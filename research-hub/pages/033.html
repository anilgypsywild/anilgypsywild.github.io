📊 Analytics Research Brief: Compassion Causes Platform

Prepared by: [account removed] ; Date: Aug 11, 2025
Prepared for: [account removed] , [account removed]

🎯 Objective

To implement analytics tracking across the Causes platform that enables measurement of user behaviors, trust signals, and UX effectiveness for all user types - New Users, NextGen, CurrentGen, and High-Impact Donors (HIDs). The goal is to generate actionable insights for iterative UX improvements.

🗒️ 1. Executive Summary

This analytics research brief outlines the strategic implementation of behavioral tracking across key touchpoints of the Compassion Causes platform.

It aligns with the platform’s 4D UX Benchmark dimensions (Doability, Dependability, Delight, Desire) and includes Critical Biannual Benchmark Tasks, which will be tested twice a year to measure platform evolution.

Analytics tools: Quantum Metrics (preferred)

🔎 2. Research Goals

  1. Understand behavioral engagement across all user types
  2. Monitor task success and frustration levels for benchmark tasks
  3. Track response to trust signals, storytelling, and social proof
  4. Measure conversion, retention, and advocacy metrics

⚖️ 3. Core Benchmark Tasks (Measured Twice a Year)

These seven benchmark tasks are prioritized for biannual analytics instrumentation:

Task 1: Discover & Select a Cause

  • Event Tags: cause_exploration_started, filter_used, cause_selected
  • KPI: Task success rate, time-on-task, ease score (CSAT)

Task 2: Understand Cause Details & Allocation

  • Event Tags: cause_detail_viewed, allocation_info_clicked, trust_score_rated
  • KPI: Trust Confidence Score, SUPR-Q clarity score, page engagement duration

Task 3: Simulated Donation + MWTP

  • Event Tags: donation_started, donation_completed, mwpt_value_entered
  • KPI: Ease of Use, MWTP average, donation abandonment rate

Task 4: Navigate Using Filters

  • Event Tags: filter_applied, filter_category_selected, cause_selected
  • KPI: Filter efficiency rate, task completion time, filter CSAT score

Task 5: Evaluate Trust Indicators (Social Proof)

  • Event Tags: testimonial_viewed, badge_clicked, nps_survey_completed
  • KPI: Trust Score, Social Proof Engagement Rate, NPS

Task 6: Catch Trial – Search for Non-Existent Cause

  • Event Tags: search_submitted, search_error_displayed, fallback_option_clicked
  • KPI: Resilience Score, frustration indicators (rage click, looping), error recovery time

Task 7: Post-Donation Feedback & Follow-up

  • Event Tags: confirmation_seen, thank_you_engaged, impact_alert_clicked, social_share
  • KPI: Post-donation CSAT, open-rate, follow-up action engagement

:people_holding_hands_dark_skin_tone_medium_skin_tone: 4. Platform-Wide Events to Track (All Users)

Onboarding & Session Tracking

  • session_start, onboarding_started, onboarding_completed, tutorial_skipped
  • KPI: Onboarding Completion %, Tutorial skip rate

Trust Signals Engagement

  • trust_element_displayed, trust_element_clicked, trust_confidence_scored
  • KPI: Average Trust Confidence Score, engagement with trust cues

Donation Behavior

  • donation_flow_started, amount_selected, gift_submitted
  • KPI: Conversion rate, drop-off rate, MWTP regression by archetype

Error Handling & Recovery

  • search_no_results, error_displayed, fallback_option_used
  • KPI: Error recovery time, abandonment rate

Narrative & Emotional Engagement

  • story_viewed, video_played, story_emotion_tagged
  • KPI: Engagement duration, emotional resonance rate

Advocacy & Referral Behavior

  • referral_shared, gamification_triggered, nps_survey_submitted
  • KPI: % Promoters, referral conversion rate

🧩 5. Data Segment Dimensions

  • User Type: New User, NextGen, CurrentGen, HID
  • Device Type
  • Geographic Region
  • Entry Path (organic, email, social)
  • Cause Category of Interest

6. Next Steps

  1. Align with Product, Engineering, and Marketing on event naming conventions
  2. Integrate tracking into staging environment by Oct 1, 2025
  3. Run biannual benchmark tests (next: Dec 2025)
  4. Validate key flows with A/B testing variants
