Unlocking True User Needs: JTBD vs User Story

User Story: CVG UX User Stories Workshop Shared.pptx

Step 1: Understand the User Actions (from the image)

Sequence:

  1. Watched a BASE jump video → felt awe/inspired
  2. Reflected: “Could I go there someday?”
  3. Searched comments for validation/curiosity
  4. Noticed someone voiced a similar question
  5. Viewed their profile
  6. Saw they were credible, had experience, shared stories
  7. Built trust, felt inspired, dream felt possible

Step 2: What’s a User Story?

A User Story describes a specific feature or requirement from the user’s perspective, usually in this format:

As a [type of user], I want to [do something] so that [I get a benefit].

Example from above:

As an adventure-seeker, I want to see real stories from people who’ve done BASE jumps, so I can feel inspired and know it’s possible for me too.

Step 3: What’s a JTBD?

A Job-To-Be-Done looks at the deeper progress a user is trying to make in their life, regardless of the current solution or product. JTBD is more about the underlying “job” or goal the user hires a product/service to accomplish.

JTBD Format:

When [situation], I want to [motivation], so I can [expected outcome].

Step 4: Convert the Actions into a JTBD

Let’s synthesize the actions:

JTBD Statement

When I see something awe-inspiring (like a BASE jump video) that sparks a dream, I want to find relatable, trustworthy stories from real people who have done it, so I can believe it’s possible for me and feel confident to pursue it myself.

Step 5: Teaching Note

JTBD vs User Story: Key Differences

  • JTBD is about the outcome or progress a user seeks in their life, not about features.
  • User Story is about a specific feature or functionality a user wants in your product.

JTBD Example (from above):

When I feel inspired by a daring adventure, I want to connect with credible people who have done it, so I can see it’s achievable and take steps towards it myself.

User Story Example:

As a user, I want to read comments from experienced jumpers, so I can get tips and reassurance.

Reference

  • Ulwick, A. W. (2016). Jobs to be Done: Theory to Practice. Idea Bite Press.
  • Christensen, C. M., et al. (2016). Competing Against Luck: The Story of Innovation and Customer Choice. Harper Business.
