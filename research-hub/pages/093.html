Causes: UX ScoreCards and Summary by User Group

🔥 Todo: End-Point for All Scale

This report analyzes user experience (UX) metrics to present UX ScoreCards for the Causes platform, highlighting areas for improvement in user satisfaction, usability, and efficiency across two user groups: Supporter Operations(SO) and Friends&Family (FF).

While Friends&Family on Web and Mobile score highly on satisfaction and usability, Suppoter Operations users on Mobile shows lower scores in task time, ease of use, and NPS.

Key recommendations focus on refining mobile workflows and addressing user feedback to boost satisfaction and loyalty across the platform.

Insights on User Satisfaction, Usability, and Improvement Opportunities.

Task Time Observation

  • Users on the mobile platform (both SO and FF) take longer to complete tasks compared to the web platform.
  • Next Steps: Conduct usability testing focused on mobile workflows to identify any specific steps or screens that may be causing delays. Optimize key user flows for mobile, such as donation processing and account management, to reduce friction and make the process quicker.

Task Success Observation

Task success is high across all platforms (91-100%), indicating that most users can complete their goals.

Ease of Use Observation

SO Mobile scored lower (3.83) on ease of use than the other platforms. Next Steps: Review qualitative feedback from SO Mobile users to understand the specific pain points affecting ease of use. Consider making UI adjustments based on feedback, such as simplifying navigation, or reducing cognitive load.

Customer Satisfaction Score (CSAT) Observation

Scores are relatively consistent, though SO Mobile scored slightly lower (5.75).

Net Promoter Score (NPS) Observation

  • SO Mobile has a lower NPS of 50 compared to 63 for SO Web and 100 for both FF platforms.
  • Next Steps: Explore the causes of SO Mobile users being more neutral or passive. This could be achieved by interviewing SO Mobile users in the passive category to understand what would make them enthusiastic promoters. Prioritize improvements to mobile features like donation and sharing capabilities to foster loyalty and increase recommendation likelihood.

System Usability Score (SUS) Observation

  • Scores are relatively high across all platforms, though SO Mobile is slightly lower (75.71).
  • Next Steps: Conduct a detailed UX audit on SO Mobile to uncover usability issues that might affect the user experience. These can be minor issues (e.g., unclear icons, difficult-to-read text) that cumulatively affect the SUS.

Emotion Observation

  • SO Mobile users are not as satisfied as other groups, reporting an experience between "Very Happy" and "Happy."
  • Next Steps: Conduct emotional mapping to explore where users feel frustrated or disengaged. This could involve identifying specific moments in the user journey that need improvements, such as reducing donation time or enhancing mobile navigation.

Summary of Key Actionable Improvements

  1. Focus on SO Mobile Improvements: Conduct further research to understand why SO Mobile is rated lower across ease of use, NPS, and CSAT.
  2. Optimize Mobile Usability: Make targeted changes to improve task times, such as simplifying the donation flow and ensuring navigation is intuitive.
  3. Increase NPS for SO Mobile: Convert passive users into promoters by enhancing the mobile experience with user-requested features and performance improvements.
  4. Continuous User Feedback: Implement a feedback loop on mobile platforms to capture ongoing insights about user experiences and sentiments.

CSAT Insights

The Customer Satisfaction Score (CSAT) reflects how satisfied users are with their experience on the platform, with scores on a scale where higher numbers indicate greater satisfaction.

  • In this scorecard, SO Web users report the highest CSAT (6.11), indicating generally high satisfaction.
  • SO Mobile users report a lower score of 5.75, suggesting slightly less satisfaction compared to other platforms. This could indicate issues specific to mobile that detract from their overall experience.
  • FF Web and FF Mobile users have similar satisfaction levels (6.0), implying a positive but slightly lower satisfaction level for FF Mobile compared to SO Web.

Suggested Next Steps for CSAT Improvement

  1. Identify the Root Causes of Lower Satisfaction on SO Mobile: SO Mobile users' lower satisfaction score suggests that certain pain points are impacting their experience.

    Conduct user interviews or surveys to dive deeper into specific aspects they find dissatisfactory, such as navigation, speed, or clarity of options.

  2. Implement Targeted UX Enhancements: Based on feedback, prioritize improvements that can boost satisfaction, such as ensuring a smoother donation experience, reducing response times, and enhancing user interface (UI) clarity.

  3. Monitor CSAT After Changes: After implementing changes, continuously monitor the CSAT on SO Mobile to see if satisfaction levels improve, indicating a positive response to the adjustments. Improving the CSAT, especially on SO Mobile, will be key in increasing overall user contentment and loyalty across platforms.

NPS Insights

Net Promoter Score (NPS) measures users' likelihood to recommend the platform, divided into Promoters (enthusiastic supporters), Passives (neutral users), and Detractors (unenthusiastic users). Higher scores indicate strong loyalty and user advocacy.

  • SO Web has an NPS of 63, with 21% Promoters, 20% Passives, and 9% Detractors. This score is good, but there’s room to convert Passives to Promoters and reduce Detractors.
  • SO Mobile has an NPS of 50, with 50% Promoters and 50% Passives, showing lower loyalty compared to other platforms, with no Detractors but a high percentage of Passives.
  • FF Web and FF Mobile both scored a perfect 100, with 100% Promoters, indicating extremely high satisfaction and likelihood to recommend among FF users on both platforms.

Suggested Next Steps for NPS Improvement

  1. Convert SO Mobile Passives to Promoters: The large number of Passives on SO Mobile suggests areas for potential improvement. Focus on understanding what would make SO Mobile users enthusiastic about recommending the platform, possibly through targeted feedback surveys and user interviews.
  2. Reduce Detractors on SO Web: The presence of 9% Detractors on SO Web signals some dissatisfaction. Investigate specific pain points that these users encounter by reviewing feedback or conducting follow-up interviews, and address these areas to enhance their experience.
  3. Continue Building on FF Web and Mobile Success: Since FF users report perfect NPS scores, examine what features and aspects contribute to their satisfaction. Use these insights to reinforce or replicate successful elements in the SO platform to foster similar loyalty

System Usability Score (SUS) Insights

SUS evaluates the overall usability and user experience of the platform, where scores above 70 indicate good usability.

  • SO Web scored 80.01, reflecting strong usability, but still with room for small improvements.
  • SO Mobile scored 75.71, lower than the other platforms, indicating some usability challenges that may need addressing.
  • FF Web and FF Mobile both scored 82.48, suggesting high usability and a smooth experience on these platforms.

Suggested Steps for SUS Improvement

  1. Enhance SO Mobile Usability: The slightly lower SUS score on SO Mobile suggests some usability challenges. A focused usability audit on SO Mobile can help identify friction points, such as unclear navigation, difficult-to-use buttons, or too many steps in key processes. Addressing these can improve the mobile experience and increase the SUS score.
  2. Optimize SO Web for Further Usability Gains: Although SO Web scored well, further improvements can elevate the experience to match FF levels. Simplify workflows, add contextual help, or enhance visual hierarchy based on user feedback to make interactions even smoother.

Summary of Actionable Steps for NPS and SUS

  1. Increase SO Mobile User Loyalty (NPS): Convert Passives into Promoters by addressing areas they feel are lacking. Enhanced ease of use, simplified navigation, and improved satisfaction should help.
  2. Reduce Detractors on SO Web: Address specific issues identified by Detractors on SO Web, potentially through targeted updates or feature adjustments.
  3. Improve Usability on SO Mobile (SUS): Conduct a usability audit to identify and resolve any specific challenges on SO Mobile, making the platform as smooth and intuitive as possible.
  4. Sustain High NPS and SUS on FF Platforms: Replicate the success factors from FF Web and Mobile on SO platforms to ensure consistently high scores across the board.

Implementing these changes can improve overall usability and user loyalty, creating a better and more recommended experience across all platforms.
