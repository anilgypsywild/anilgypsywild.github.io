Usability Tasks for Baseline UX Testing

These usability tasks will help establish a baseline UX score using SUPR-Q metrics, highlighting ease of use, clarity, trust, and overall user engagement.

  1. Exploring Causes
    • Task 1: Find a cause related to education in Africa and check how funds are utilized.
    • Task 2: Use the Causes filtering options to identify a high-urgency cause near you.
  2. Donating to a Cause
    • Task 1: Select a cause and go through the donation process, stopping just before payment.
    • Task 2: Try to understand the different payment options available and how donations are processed.
  3. Receiving Impact Updates
    • Task 1: Locate a section where past donors can check impact updates on a funded cause.
    • Task 2: Sign up for email or SMS updates on a cause and confirm the confirmation process.
  4. Understanding the Organization's Approach
    • Task 1: Find information on how Compassion Causes allocates donations and supports transparency.
    • Task 2: Locate and read the FAQ section to understand donation security and tax benefits.
  5. Creating and Managing Fundraisers (if applicable)
    • Task 1: Try to create a fundraiser for a specific cause and customize the description.
    • Task 2: Locate the dashboard where you can track contributions to your fundraiser.
  6. Engaging with the Community
    • Task 1: Post a comment or testimonial on a funded cause (or find where to do so).
    • Task 2: Search for and engage with an existing discussion or testimonial from another donor.
