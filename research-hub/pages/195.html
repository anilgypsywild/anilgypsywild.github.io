0. Objective

  2. How one set of notes becomes quantitative metrics.

Qualitative Themes

  • Bangkok: excitement and curiosity.
  • Chiang Mai: trust concerns but clear utility.
  • Udon Thani: hesitation, language anxiety, fear of mistakes.

5. Example ANOVA for NASA-TLX (Mental Demand)

Site Scores Mean
Chiang Mai 3, 4, 3, 2 3.0
Bangkok 2, 2, 2 2.0
Udon Thani 6, 5, 4 5.0

Statistical test: One-way ANOVA, Factor = Site, DV = NASA-TLX score
Result (illustrative): F(2, 7) = 9.6, p < .01 → significant difference.

Interpretation:
Cognitive workload differs by site. Udon Thani users find the AI workflow significantly more demanding. This guides design adaptation for language, literacy, and contextual support before scaling nationwide.

How to Use This Section:
PMs and Designers can copy the note-taking fields directly during sessions, then fill the metric table for each participant.
Anil will handle aggregation, statistical testing, and executive-level synthesis.
