Research article

🎯 Objective

Translate the existing Causes UX ScoreCard (Dec 2024) into the 4D UX View: Doability, Dependability, Delight, and Desire, using the metrics already captured: SUS, CSAT, NPS, Task Time, Task Success, Ease of Use, and Emotion.

Approach: Map Causes UX ScoreCard Dec 2024 into the new 4D UX framework (Doability, Dependability, Delight, Desire), along with an analysis of how the existing metrics align with each pillar. This mapping will serve as a model for updating legacy UX reports across into a consistent 4D format.

🔍 Key Takeaways

  • FF cohorts (Web & Mobile) consistently outperform across all 4D pillars. Strong usability, satisfaction, and promoter signals.
  • SO Web performs reasonably well but has room to improve on trust (NPS) and task time.
  • SO Mobile is clearly the lowest-performing cohort:
    • High task time (10:48)
    • Weak ease of use (3.83)
    • Lowest CSAT (5.75)
    • Lower loyalty (NPS 50)

📌 Suggested Next Steps for SO Mobile

Priority Area Action
Doability Audit mobile flows for bottlenecks. Simplify key tasks.
Dependability Interview passive users to identify confidence gaps.
Delight Emotional journey mapping to find friction points.
Desire Reduce time-to-value and increase visible feedback.

✍ Appendix: Why This Mapping Works

  • Continuity: All legacy metrics fit cleanly into the 4D framework—no rework needed.
  • Clarity: Each UX pillar addresses a distinct user outcome, letting Product and Design act fast.
  • Comparability: Enables scorecard-to-scorecard benchmarking across cohorts, platforms, and teams.
  • Credibility: Uses standard, validated instruments (SUS, NPS, CSAT) to ground decisions.
