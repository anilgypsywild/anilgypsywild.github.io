Donor-Validated Feature Priority Framework for the Causes Platform

A Kano-Informed Model for Understanding Essential, High-Impact, and Trust-Building Features

Causes Feature Prioritization Study: Identifying Must-Have, Performance, and Delighter Features for 2025 Roadmap

Prepared for:

  • [name omitted] (Product Lead, Causes)
  • [name omitted] (UX Director)
  • [name omitted] (Design)
  • Engineering Leads (TBD)
  • Marketing / Donor Experience (as needed)

1. What Problem Are We Solving?

The Causes platform includes a mix of features such as: transparency tools, storytelling elements, updates, and donor connection features. However, the team currently lacks a donor-validated understanding of which features are:

  1. essential (“must-have”)
  2. performance-driving
  3. emotionally resonant (“delighters”)
  4. low-value or optional

Without a structured understanding of feature importance, prioritization for 2025 risks being driven by internal assumptions rather than donor needs.

We need a fast, statistically valid way to determine which features matter most to donors so that the team can confidently prioritize the Causes roadmap.

2. Why Solve This Now?

  • Causes product planning could use more donor-focused clarity. [name omitted] needs a donor-informed prioritization framework when roadmap discussions resume.
  • Improves donor trust & motivation. Feature importance directly affects transparency, clarity, emotional impact, and likelihood to donate again.
  • Maximizes engineering efficiency. Prevents over-investment in low-impact features and protects time for high-value work.
  • Holiday timing is ideal. Can run quickly with a small but statistically appropriate donor sample.
  • Creates a reusable prioritization model. Results will support future experiments, A/B testing, segmentation, and long-term UX strategy.

3. What Do We Know Today?

Past Causes research and benchmarks show:

  • Donors value transparency, clarity, and authentic stories.
  • Some features (like updates, impact visibility) strongly affect trust.
  • NextGen donors require emotional resonance and narrative clarity.
  • Prospects often struggle to understand the purpose of Causes without guidance.
  • High Impact Donors (HIDs) need deeper trust signals and transparency.
  • We have qualitative insight into donor preferences, but no quantitative, ranked feature prioritization model.

We do not know:

  1. Which features are truly essential?
  2. Which features donors would miss if removed?
  3. Which features drive repeat giving or trust?
  4. Which features should be sequenced first in the 2026 roadmap?
  5. How priorities differ by donor segment>

This KANO study fills that gap.

4. What Will We Do With the Results?

The outcomes will provide:

A. A Donor-Validated Feature Prioritization Framework

Identifying:

  1. Must-Have Features
  2. Performance Drivers
  3. Delighters
  4. Low-Value / Optional Features

B. A Input for Cause's Roadmap

Enables product to prioritize with confidence and reduce churn in planning.

C. Segmentation Insights

Differences across:

  • Prospects
  • CurrentGen
  • NextGen
  • SMB
  • HIDs

D. Data for a Reusable Decision Framework

This becomes the baseline for:

  • future experimentation
  • feature-level A/B tests
  • new cause launches
  • refinement of storytelling & transparency features

5. Research Questions

  1. Which Causes features do donors consider essential for trust and clarity?
  2. Which features meaningfully increase likelihood to donate or donate again?
  3. Which features emotionally resonate and deepen donor connection?
  4. Which features are perceived as optional or low impact?
  5. How does feature importance differ by donor type or demographic?

(Note: Kano question set stored separately; not included in this brief.)

6. Methodology Overview

  • Survey Method: Kano-informed feature prioritization survey
  • Sample Size: 40–80 donors across segments (statistically valid for Kano distribution patterns)
  • Segmentation: Prospects, CurrentGen, NextGen, SMB, HIDs
  • Metrics:
    • Functional & dysfunctional sentiment
    • Behavioral impact (likelihood to donate)
    • Importance
    • Emotional connection
  • Output Models:
    • Feature classification
    • Feature prioritization matrix
    • Segmented feature hierarchy
    • Roadmap suggestions

7. Participants & Recruitment

  • Warm outreach to existing donors
  • NextGen panel
  • Prospects from Causes onboarding
  • HID sample (optional, if available)
  • Incentives: none required (fast, light survey)

8. Deliverables

  • Feature classification model (must-have, performance, delighter, low priority)
  • Segmentation breakdown
  • Feature prioritization scorecard
  • Executive summary (1-page)
  • Roadmap recommendations for Causes' product planning

  • Segmented insights that PM and leadership find actionable
  • Causes roadmap informed directly by donor data
  • Reduction in ambiguity or debate around feature priority
  • Reusable survey instrument for future cycles
