🚧 ...Research Protocol: First-Time and Returning User Experience Validation [Work in Progress...]

Project Name: First-Time and Returning User Experience Validation (Homepage, Donation Flow, Returning User Engagement)
Requestor: Chad (Design)
Research Owner: Anil (UX Research)
Target Participants: First-time users and returning users (segmented using product analytics signals)

1. Purpose and Goals

The purpose of this study is to evaluate new user onboarding and returning user engagement experiences for the Compassion Causes platform with the UCD process.

This research will:

  • Assess whether first-time users can understand the platform, explore Causes, and complete a donation with confidence.
  • Evaluate the new homepage and donation flow for clarity, trustworthiness, and resonance.
  • Identify what information and features drive returning user engagement (e.g., impact tracking, global map exploration, mobile app vs browser preferences).
  • Create a UX 4D Scorecard baseline for first-time and returning user experience.

Why Now:

  • Early sandbox testing combined with product analytics is critical to validate design direction and close usability gaps before engineering investment.
  • Tracking signals for first-time and returning user behavior will allow us to monitor success longitudinally.

2. Objectives by UX 4D Pillars

⚙ Doability (Can users do it?)

  • Can first-time users identify what the platform is and how to start?
  • Can users find Causes and complete the donation flow without confusion?
  • Which information is most critical on the homepage and Cause detail pages?
  • Are navigation elements (e.g., global map) understandable and usable?

🛡 Dependability (Do users trust it?)

  • Does the donation interaction feel safe and trustworthy?
  • Are confirmation and post-donation communications sufficient to build confidence?
  • Do returning users trust that their previous donations had an impact?

🌟 Delight (How does it feel?)

  • Does the homepage and Cause experience emotionally resonate with first-time users?
  • Which elements (images, stories, data) evoke connection and satisfaction?
  • Do returning users feel motivated to explore or give again?

💡 Desire (Do they want more?)

  • Would users prefer a dedicated mobile app vs the mobile browser?
  • Do returning users want to see their impact and track donations?
  • What features or content would make them come back and engage again?

3. Research Questions

First-Time Users:

  1. Does the homepage clearly communicate what the platform is and what to do? (Doability)
  2. Which homepage and Cause details resonate most emotionally? (Delight)
  3. Is the donation flow clear, error-free, and trustworthy? (Doability, Dependability)
  4. What information do users expect immediately after donating? (Dependability, Delight)

Returning Users:

  1. Do users prefer mobile app access vs browser for repeat use? (Desire)
  2. Does a global map exploration option add value for Cause discovery? (Doability, Desire)
  3. Do users want to see their impact, follow donations, or engage in other activities? (Delight, Desire)
  4. Does the platform build enough trust to drive future donations? (Dependability, Desire)

4. Methodology

Format:

  • Remote moderated usability testing (sandbox environment) using prototypes and early builds.
  • Segmented sessions for first-time and returning users.
  • 8–10 participants per segment.

Complementary Analytics:

  • Event-based segmentation and metrics to track behaviors before, during, and after the study.

Key Metrics:

  • SUS (System Usability Scale)
  • Time-on-task and error rate for core tasks
  • CSAT and trust measures post-donation
  • Emotional resonance (word associations, sentiment scale)

5. Analytics Tracking Recommendations

To support segmentation and long-term monitoring, Research recommends adding the following product signals:

First-Time Users

  • First Session: Identify users with no prior user ID.
  • Homepage Explore Clicks: Track clicks on primary CTAs (Explore, Donate).
  • First Cause View: Time-to-first Cause detail page view.
  • First Donation Attempt: Start and completion metrics, error rate.

Returning Users

  • Returning Session Flag: Recognize users with repeat visits (via user ID or cookies).
  • Cause Discovery Events: Map toggle usage, search activity, filter usage.
  • Impact Dashboard Views: Frequency and depth of impact content interactions.
  • Re-Engagement Donations: Time-to-next donation, repeat donation value.

Shared Metrics

  • Conversion funnel (Homepage → Cause → Donation Start → Donation Complete)
  • Drop-off points by segment
  • Engagement with emotional content (stories, images, videos)

Tools: GA4, Mixpanel, or equivalent event-based analytics tools.

6. Hypotheses

  • H1: If first-time users can clearly understand the homepage purpose and actions, then they will complete their first donation at a higher rate (Doability, Dependability).
  • H2: If users see emotionally resonant Cause details, then they will report higher satisfaction and likelihood to return (Delight, Desire).
  • H3: If returning users have an easy way to track their impact, then repeat donation frequency will increase (Dependability, Desire).
  • H4: If global map exploration is intuitive, then engagement and session length will increase (Doability, Desire).

7. Deliverables

  • UX 4D Scorecard baseline for first-time and returning user experience.
  • Prioritized usability fixes (Doability, Dependability) and engagement drivers (Delight, Desire).
  • Analytics event map to continue monitoring post-launch.

8. Next Steps

  1. Align with Design on prototype readiness and scenarios.
  2. Implement event tracking signals listed in Section 5.
  3. Recruit participants segmented by first-time vs returning status.
  4. Run sandbox usability testing sessions and capture both qualitative and quantitative data.

Appendix: Draft 4D UX Scorecard

Question / Topic First-Time or Returning User 4D Pillar Metric / Measurement Success Criteria (Baseline)
Does the homepage clearly communicate what this platform is and what to do? First-time Doability SUS clarity score, Time-to-first click, Task success rate 80%+ users understand purpose and act within 10 seconds
Which information is most important when viewing a Cause? Both Doability / Delight Heatmaps, Click-through rate on Cause elements, Importance ranking Users prioritize the right content (Cause purpose, impact) in the top 3
Is the donation interaction clear and trustworthy? First-time Doability / Dependability SUS trust and clarity scores, error rate, abandonment rate 90%+ complete without confusion, 80%+ trust scores
What do users expect immediately after donating? First-time Dependability / Delight Open-ended feedback, CSAT, Task completion (confirmation view) 80%+ feel reassured and know what happens next
Would returning users prefer a mobile app vs mobile browser? Returning Desire Preference question, qualitative rationale Clear majority preference (70%+) with actionable reasons
Would exploring Causes via a global map be valuable? Returning Doability / Desire Task success, engagement rate with map toggle, preference ranking Users can complete map-based exploration within 2 clicks
Do returning users want to see impact, follow donations, or engage in other activities? Returning Desire / Delight Open-ended feedback, CSAT, feature prioritization Clear top 2 features for engagement identified
Does the platform build enough trust for returning users to give again? Returning Dependability Trust score, repeat donation intention (Likert) 80%+ say they trust platform and would donate again

How to use this Scorecard

  • Baseline scores will be established during sandbox usability testing.
  • Metrics will be tied to analytics events (conversion funnels, task completion, repeat visits) to track improvements longitudinally.
  • This scorecard can be updated after each test cycle and tied into the broader UX metrics framework.
